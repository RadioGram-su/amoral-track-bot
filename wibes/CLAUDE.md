# Проект Wibes: продающие ИИ-обзоры товаров Wildberries

Эта папка — память проекта, перенесённая из облачной сессии Claude Code (26–27.11.2026).
Сессия запущена локально на Windows-ПК пользователя. К ПК по USB подключён Android-телефон
с открытым приложением Wibes (аккаунт уже зарегистрирован). Общение — на русском.

## Цель
Зарабатывать на коротких вертикальных роликах-обзорах товаров WB в Wibes (контентплейс Wildberries):
ИИ делает разбор отзывов, сценарий, озвучку и видео; пользователь (или скрипт) загружает.

## Что уже выяснено (факты)
- **Загрузка роликов работает в браузере**: `https://wibes.ru/create`
  - поле «Описание» — до 660 символов;
  - «Добавьте товары» — по **артикулу WB**, можно несколько;
  - контент: mov, mp4, jpeg, png, webp; видео от 2 с; до 1 ГБ;
  - после «Опубликовать» — модерация от нескольких минут до 2 часов.
- **Монетизация подключается только в мобильном приложении** (на сайте `wibes.ru/monetization` показывает QR на приложение).
- Условия монетизации (данные 2025 года, на 2026 не подтверждены — сверять в приложении):
  - 100 ₽ за 1000 просмотров роликов с товарами WB; нужно ≥2 роликов от 5 с; автор не должен быть продавцом WB;
  - ~9,9% с выкупленных продаж (CPO, с 01.06.2025, раньше 5%); товары для продвижения — в «витрине предложений»;
  - нужен статус самозанятого или ИП.
- Партнёрка WB работает только внутри Wibes (внешних партнёрских ссылок WB нет).
- Ссылка на товар по артикулу: `https://www.wildberries.ru/catalog/<АРТИКУЛ>/detail.aspx`.

## Открытые вопросы — проверить первыми
1. Засчитываются ли в монетизацию ролики, загруженные через сайт (а не из приложения)? → залить 1 тестовый ролик с сайта, проверить в приложении.
2. Платят ли % за любой артикул или только за товары из витрины предложений?
3. Как Wibes относится к ИИ-роликам и однотипным шаблонным видео (см. «Правила платформы» и пользовательское соглашение, пункт про автоматизацию/ботов)?
4. Нужна ли маркировка рекламы (ERID) для таких роликов, или Wibes делает её сам.

## Правила работы
- **Не выдумывать товары, артикулы, цифры и отзывы.** Всё — только с экрана телефона, карточки WB или реальных отзывов.
- Свойства товара в сценарии — только из карточки и отзывов; без «лучший/№1» и медицинских обещаний; в каждом ролике честный минус.
- Ключи API (ElevenLabs, Yandex и т.п.) — только в `.env` (он в .gitignore), никогда не коммитить.
- Видео, скриншоты и прочие тяжёлые файлы — в `wibes/output/` и `wibes/screens/` (в .gitignore).
- Массовую автозагрузку не включать, пока не проверены правила площадки (риск бана аккаунта с монетизацией).

## Следующие шаги (по порядку)
1. **Подключиться к телефону через adb** и прочитать витрину предложений Wibes — см. раздел «Работа с телефоном» в PLAN.md.
2. Выбрать 10 товаров по скорингу из PLAN.md → заполнить `products.md` (артикул, ссылка, цена, рейтинг, отзывы, % из витрины, рубрика, баллы).
3. Для топ-3 товаров написать сценарии по шаблону из PLAN.md + описания до 660 символов.
4. Собрать пайплайн: артикул → данные карточки и отзывы → разбор отзывов ИИ → сценарий → озвучка (ElevenLabs у пользователя есть; альтернатива — Yandex SpeechKit) → видео 1080×1920 (ffmpeg) → папка `output/<артикул>-<рубрика>/` с `video.mp4`, `описание.txt`, `артикулы.txt`.
5. Тест: 1 ролик через `wibes.ru/create` → проверить засчёт в монетизации → потом поток 3 ролика/день.
