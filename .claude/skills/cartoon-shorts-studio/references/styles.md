# Style library

Each style is a reusable **style block**: paste it at the start of every image and video prompt
for the episode so all shots match. Describe qualities, never a studio, franchise or living artist.
Mix two styles or change the palette to make the channel's look unique, then freeze it in the
character bible.

## How to make a style "yours"

1. Pick one base style plus one twist (palette, material, lighting or camera).
2. Define the palette as 4–6 HEX colours and reuse it everywhere, including captions.
3. Add a signature element that appears in every episode (a prop, a background motif, a transition).
4. Lock the camera language: for example always a low angle for the hero, always a whip-pan between scenes.
5. Write the final style block into the character bible and never edit it mid-series.
