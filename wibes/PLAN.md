# План: продающие обзоры в Wibes

## 1. Выбор товаров из витрины (скоринг)
Берём товары с суммой **≥7 из 10**:

| Критерий | Баллы |
|---|---|
| Рейтинг ≥ 4,7 | 2 |
| ≥ 500 отзывов (есть материал для разбора) | 2 |
| Цена 500–3000 ₽ (импульсная покупка) | 2 |
| Эффект виден в кадре за 3 секунды | 2 |
| Подарочный потенциал к Новому году (сейчас сезон) | 1 |
| Высокий % в витрине | 1 |

**Отсекаем:** одежду и обувь (размеры → возвраты, а % платят только за выкуп), БАДы, косметику с медицинскими обещаниями, товары известных брендов (риск претензий правообладателей).

**Приоритет на декабрь:** подарки до 500 / 1000 / 2000 ₽ («Тайный Санта»), зимнее для авто (щётки, скребки, подогрев), уют и декор, кухонные мелочи, дети, животные.

## 2. Рубрики (6 штук)
1. **«Прочитал 1000 отзывов за тебя»** — главная рубрика: 3 плюса + 1 минус из реальных отзывов + вердикт.
2. **«Подарок до N ₽»** — новогодняя серия, ежедневно до 31.12.
3. **«Брать или нет?»** — честный вердикт: минусы и кому не подойдёт.
4. **«Дорого vs дёшево»** — два похожих товара, оба артикула в одном ролике.
5. **«Решает [проблему] за 5 секунд»** — демонстрация работы.
6. **«Топ-3 для [кухни / машины / кота]»** — 3 артикула в одном ролике.

## 3. Шаблон сценария (25–35 секунд)

| Время | Кадр | Голос |
|---|---|---|
| 0–2 с | Крупный план + текст-крючок | «Это купили 50 тысяч человек. Я прочитал их отзывы.» |
| 2–6 с | Проблема | «Если у тебя вечно [боль]…» |
| 6–15 с | Демонстрация: фото/видео из карточки, зум, смена ракурса | 2–3 ключевые функции |
| 15–22 с | Цитаты из отзывов на экране, звёзды | «Чаще всего хвалят: …» |
| 22–27 с | Минус и кому не подойдёт | «Но есть нюанс: … Если важно X — не берите.» |
| 27–30 с | Цена + стрелка вниз | «Товар прикреплён под видео.» |

Оформление: 1080×1920; крупные субтитры по центру; первый кадр = обложка; без чужой музыки (только свободная фоновая или без музыки).

Числа в крючке («50 тысяч человек», «1000 отзывов») — только реальные, из карточки.

## 4. Пайплайн производства
1. Артикул → со страницы товара: фото/видео, характеристики, цена, рейтинг, 300–1000 отзывов.
2. ИИ-разбор отзывов: частые плюсы, частые минусы, частые вопросы, 2–3 короткие реальные цитаты.
3. Сценарий по шаблону п.3.
4. Озвучка: ElevenLabs (у пользователя есть аккаунт) или Yandex SpeechKit. Ключ — в `.env`.
5. Сборка видео (ffmpeg): фото/видео карточки + зум/панорама + субтитры + голос.
6. Описание ≤ 660 символов: крючок → 3 пункта → «товар прикреплён» → 3–5 хэштегов.
7. Выход: `output/<артикул>-<рубрика>/` → `video.mp4`, `описание.txt`, `артикулы.txt`.
8. Загрузка: `https://wibes.ru/create` (вручную ~30 с на ролик; автоматизация — только после проверки правил).

## 5. Правила, чтобы не забанили
- Свойства товара — только из карточки и отзывов. Ничего не придумывать (недостоверная реклама).
- Цитаты — только реальные. Без «лучший», «№1», без медицинских обещаний.
- В каждом ролике есть минус — это честно и повышает доверие.
- Не делать ролики под копирку: чередовать рубрики, крючки и визуальные шаблоны.

## 6. График и метрики
- **Неделя 1:** 10 товаров × 2 ролика в разных рубриках = 20 роликов, по 3 в день.
- **Неделя 2:** по каждому ролику — просмотры и продажи из раздела «Монетизация» в приложении. Топ-3 товара/рубрики → ещё по 3–5 роликов, остальные убрать.
- **A/B крючков:** один товар — два ролика с разными первыми 2 секундами; победитель становится шаблоном.
- **Самое первое:** проверить, засчитывается ли в монетизацию ролик, загруженный через сайт.

## 7. Работа с телефоном (adb, Windows)
Подготовка (делает пользователь один раз):
- Установить Android platform-tools (adb) и добавить в PATH.
- На телефоне: Настройки → О телефоне → 7 раз нажать «Номер сборки» → «Для разработчиков» → включить «Отладка по USB». Подключить USB и подтвердить ключ RSA на экране телефона.

Команды (PowerShell; бинарный вывод через `>` в PowerShell портится, поэтому скриншот — через файл на телефоне):
```powershell
adb devices                                   # телефон должен быть в статусе "device"
adb shell screencap -p /sdcard/s.png          # скриншот экрана
adb pull /sdcard/s.png screens/s01.png
adb shell uiautomator dump /sdcard/ui.xml     # текст и координаты элементов экрана
adb pull /sdcard/ui.xml screens/ui01.xml
adb shell input swipe 540 1600 540 600 300    # прокрутка вниз (координаты под экран телефона)
adb shell input tap X Y                       # нажатие
```
Порядок: открыть в Wibes «Монетизация» → витрину предложений → скриншот + dump → прокрутка → повторить, пока не соберётся 20–30 кандидатов → скоринг → `products.md`.
Если артикул не виден в списке — открыть карточку товара (tap) и взять артикул оттуда, затем `adb shell input keyevent 4` (назад).
